# 苏格拉底式对话支架 · 网页版智能体

为开题报告《苏格拉底式对话支架》配套的**自建网页智能体**：学生输入姓名/学号后进入对话（阶段一虚拟论敌 / 阶段二策略卡），教师从后台按学生、按日期查看全部对话并一键导出 CSV。底层用**智谱 GLM-4-Flash（永久免费）**，不花一分钱。

## 一、本地运行（你自己的 Mac，课前测试用）

1. 安装依赖（只要装一次；已帮你在本机装好，换电脑才需要）：
   ```bash
   cd socratic-writing-agent
   pip3 install -r requirements.txt
   ```
2. **（推荐，不用碰终端）双击启动**：在 `socratic-writing-agent` 文件夹里**双击 `启动.command`**，
   它会自动开服务并弹出浏览器。关闭弹出的终端窗口即停止服务。
   （首次双击若提示"无法打开"，右键它 → 打开 → 仍要打开 即可；这是 macOS 对下载脚本的常规提醒。）
3. 或手动运行：
   ```bash
   python3 app.py
   ```
   终端会显示 `Running on http://0.0.0.0:8080`。
4. 浏览器打开（默认端口 **8080**，已避开 macOS 隔空播放占用的 5000）：
   - 学生端：http://localhost:8080
   - 教师后台：http://localhost:8080/admin （密码见 `.env` 里的 `ADMIN_PASSWORD`，初次已生成，请改成自己的）
   > 若想换端口：`PORT=9000 python3 app.py`，再访问 http://localhost:9000

> `.env` 已为你填好免费智谱 API key，直接 `python3 app.py` 就走**真实对话**。
> 没填 key 才会进入 **Demo 模式**（AI 回答是固定演示内容，仅用于检查界面）。

## 三·五、学生端体验说明

- **苏格拉底老爷爷形象**：页面顶部有一位白胡子老爷爷头像，AI 以“老爷爷”口吻陪学生聊天——用“你”平等交流、一次只问一个问题、用大白话，降低认知负荷，让学生愿意开口。
- **自动记住历史**：学生用相同姓名再次登录，会自动回到自己上一次的对话，能看到之前的全部聊天记录；AI 也能读到历史，**记住他之前暴露的论证薄弱点**，继续追问而不是从头再来。教师切换轮次后，学生继续登录时对话会跟随进入新阶段，历史保留。
- **每轮必须提交本轮的稿子**：不能只写一句观点（后端默认校验 ≥100 字，`MIN_ESSAY_LEN` 可改）。**第1轮粘贴前测原稿，第2轮粘贴你在第1轮之后自己改出来的升格稿**（同一篇作文的修改版）；两轮都不复用旧稿，保证每次诊断都基于本轮文本。
- **第2轮＝对照升格稿再诊断**：AI 同时拿到你第1轮的原稿、第1轮的完整对话记录、以及本轮的升格稿，先判断"上次追问你的那个断裂点补上了没有"，再针对**仍未补上（或新出现）**的断裂点追问——不会把升格稿当新作文从头问一遍，也不会重复问你已经答明白的东西。第1轮的原稿与对话记录，学生端右上角「往期对话」里可直接回看。
- **阶段一直接追问**：AI 不再先罗列“诊断结果”或“我将采取哪些策略”，而是直接抛出一个具体问题，像聊天一样自然开场（研究内核——基于断裂点追问——仍在，只是不在学生面前“报菜单”）。
- **追问有始有终，但不设轮数上限**：一组追问至少要走够三个来回（这是**下限**，避免学生答一轮就被收掉，不是到点就必须收），之后每一轮都会先判断一次「你被追问的那两三处说明白了没有」——说清楚了，就主动用「回顾看」收尾：**先替你梳理**这组对话里想清楚了什么，再请你回看自己的论证变化，最后明确告知聊到这儿；顶栏会显示「本组对话已结束」。没说明白就继续追问，不卡在固定几个来回。

## 四、教师后台怎么用

1. 打开 `/admin`，用 `ADMIN_PASSWORD` 登录。
2. 顶部可切换**当前轮次（第 1—4 轮）**——轮次决定阶段，学生端会跟随切换：
   - 第 1 轮：阶段一（虚拟论敌），**策略全开**：5 张追问策略卡均可调用，「回顾看」只用于收尾。**素材＝前测原稿**
   - 第 2 轮：阶段一（虚拟论敌），策略全开。**素材＝升格稿**（学生第1轮后自行修改的同一篇），AI 对照第1轮原稿与对话再诊断
   - 第 3 轮：阶段二（逻辑顾问），学生持六张策略卡主动追问（完整版，带问句模板）
   - 第 4 轮：阶段二（逻辑顾问），策略卡精简版（去问句模板）
3. 「对话总览」列出每名学生、对话数、最近轮次、最近活跃时间，点「查看对话」可浏览每轮完整对话——每轮标题标注**稿次（原稿／升格稿）**，并可展开查看**该轮提交的稿子全文**，便于原稿与升格稿对照编码。
4. 点「导出 CSV」下载全部对话（含姓名、学号、轮次、**稿次**、阶段、角色、策略、**图尔敏断裂点**、内容、时间），用 Excel 打开即可做 Toulmin 编码。

## 五、数据说明

- 所有对话存于本目录 `conversations.db`（SQLite 文件）。换电脑时把这个文件和整个文件夹一起拷贝即可。
- 数据库含**稿次字段** `conversations.draft_type`（原稿／升格稿）；线上旧库首次启动会**自动补列并回填**历史数据，无需手工处理、不丢数据。
- 导出 CSV 已带 UTF-8 BOM，Excel 直接打开中文不乱码。
- 编码与评分由你独立完成，本工具只负责留存原始对话文本与策略标注，符合开题报告「不使用 AI 自动编码」的要求。

## 八、本地模拟跑一组完整对话（教研演示用）

`sim/` 下的脚本能在本地用**真实模型**跑通一整组对话，用来产出「给老师看」的示例；走的是与线上完全相同的路由逻辑（同样的收尾判定、断裂点推进、跨轮次注入），只是把数据库换成本地隔离文件。

```bash
cd socratic-writing-agent
python3 sim/run.py reset                  # 清空模拟库，从头开始
python3 sim/run.py start sim/essay.txt    # 提交作文，AI 读出断裂点并开场追问
python3 sim/run.py reply "学生的回答"      # 继续下一个来回（可反复调用）
python3 sim/auto.py                       # 或按 sim/auto.py 里的预置回答一次跑到底（可断点续跑）
python3 sim/run.py dump                   # 打印本组完整对话（含每轮的策略与断裂点）
```

- 模拟库为 `sim/sim_conversations.db`，与线上的 `conversations.db` 完全隔离，随便跑不会污染学生数据。
- **教研演示前建议先清线上库**：模拟/自测产生的数据会混进后台统计。
