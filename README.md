# 苏格拉底式对话支架 · 网页版智能体

为开题报告《苏格拉底式对话支架》配套的**自建网页智能体**：学生输入姓名/学号后进入对话（阶段一虚拟论敌 / 阶段二策略卡），教师从后台按学生、按日期查看全部对话并一键导出 CSV。底层用**智谱 GLM-4-Flash（永久免费）**，不花一分钱。

## 一、本地运行（你自己的 Mac，课前测试用）

1. 安装依赖（只要装一次；已帮你在本机装好，换电脑才需要）：
   ```bash
   cd socratic-writing-agent
   pip3 install -r requirements.txt
   ```
2. **（推荐，不用碰终端）双击启动**：在 `socratic-writing-agent` 文件夹里**双击 `启动.command`**，
   它会自动开服务并弹出浏览器。关闭弹出的终端窗口即停止服务。
   （首次双击若提示"无法打开"，右键它 → 打开 → 仍要打开 即可；这是 macOS 对下载脚本的常规提醒。）
3. 或手动运行：
   ```bash
   python3 app.py
   ```
   终端会显示 `Running on http://0.0.0.0:8080`。
4. 浏览器打开（默认端口 **8080**，已避开 macOS 隔空播放占用的 5000）：
   - 学生端：http://localhost:8080
   - 教师后台：http://localhost:8080/admin （密码见 `.env` 里的 `ADMIN_PASSWORD`，初次已生成，请改成自己的）
   > 若想换端口：`PORT=9000 python3 app.py`，再访问 http://localhost:9000

> `.env` 已为你填好免费智谱 API key，直接 `python3 app.py` 就走**真实对话**。
> 没填 key 才会进入 **Demo 模式**（AI 回答是固定演示内容，仅用于检查界面）。

## 二、关于 API key 与密码

- **API key 已配好**：项目目录的 `.env` 里 `ZHIPU_API_KEY` 已填入免费 GLM-4-Flash key，程序启动时自动读取，**直接 `python3 app.py` 即可走真实对话**，无需任何额外操作。
- **想换 key / 改密码**：用文本编辑器打开 `.env`，改 `ZHIPU_API_KEY=` 或 `ADMIN_PASSWORD=`，保存后重启 `python3 app.py` 生效。
- **后台显示「已接入智谱 API（真实对话）」即成功**；若显示「Demo 模式」，说明 key 没读到位——检查 `.env` 是否在该文件夹、key 是否完整。
- 免费额度：GLM-4-Flash 永久免费、无 Token 上限，30 名学生日常使用不会花钱。

## 三、让学生访问（二选一）

- **方案 A · 你电脑当局域网服务器（最简单，课后同 WiFi 可用）**
  学生连同一个 WiFi，浏览器打开 `http://你的内网IP:8080`（`ifconfig` 查 en0 的 inet）。你电脑不能关机/合盖。
- **方案 B · 部署到云端（学生回家/手机流量也能用，推荐正式研究用）**：详见文末「第七节 · 部署到公网（Render 免费·一键）」。

## 三·五、学生端体验说明

- **苏格拉底老爷爷形象**：页面顶部有一位白胡子老爷爷头像，AI 以“老爷爷”口吻陪学生聊天——用“你”平等交流、一次只问一个问题、用大白话，降低认知负荷，让学生愿意开口。
- **自动记住历史**：学生用相同姓名再次登录，会自动回到自己上一次的对话，能看到之前的全部聊天记录；AI 也能读到历史，**记住他之前暴露的论证薄弱点**，继续追问而不是从头再来。教师切换轮次后，学生继续登录时对话会跟随进入新阶段，历史保留。
- **阶段一直接追问**：AI 不再先罗列“诊断结果”或“我将采取以下策略”，而是直接抛出一个具体问题，像聊天一样自然开场（研究内核——基于断裂点追问——仍在，只是不在学生面前“报菜单”）。

## 四、教师后台怎么用

1. 打开 `/admin`，用 `ADMIN_PASSWORD` 登录。
2. 顶部可切换**当前轮次（第 1—4 轮）**——轮次决定阶段与策略池，学生端会跟随切换：
   - 第 1 轮：阶段一，可用策略=退一步/对立面/环顾式（+回顾看收尾）
   - 第 2 轮：阶段一，可用策略=上述 + 跳出去/进一步
   - 第 3 轮：阶段二，学生持六张策略卡主动追问（完整版，带问句模板）
   - 第 4 轮：阶段二，策略卡精简版（去问句模板）
3. 「对话总览」列出每名学生、对话数、最近活跃时间，点「查看对话」可浏览每轮完整对话，每条消息都标注了使用的策略。
4. 点「导出 CSV」下载全部对话（含姓名、学号、轮次、阶段、角色、策略、内容、时间），用 Excel 打开即可做 Toulmin 编码。

## 五、数据说明

- 所有对话存于本目录 `conversations.db`（SQLite 文件）。换电脑时把这个文件和整个文件夹一起拷贝即可。
- 导出 CSV 已带 UTF-8 BOM，Excel 直接打开中文不乱码。
- 编码与评分由你独立完成，本工具只负责留存原始对话文本与策略标注，符合开题报告「不使用 AI 自动编码」的要求。

## 七、部署到公网（Render · 免费 · 一键）

> 适用：学生回家也能用、用手机流量也能访问；教师后台公网可见（请保管好后台密码）。

**为什么用 Render**：本工具是 Flask 后端 + SQLite，不能放纯静态托管；Render 支持 Python Web 服务、免费层、自动 HTTPS，且连上 GitHub 后**每次改代码推送即自动重新部署**（见下「部署后还能改网页吗」）。

**部署步骤（一次性，约 5 分钟）**：
1. 注册 GitHub（https://github.com）并新建一个空仓库（如 `socratic-writing-agent`）。
2. 把本文件夹推送到该仓库（仓库根已备好 `render.yaml` / `Procfile` / `requirements.txt`；`.env` 和 `conversations.db` 已在 `.gitignore` 中，不会上传，密钥安全）。
3. 注册 Render（https://render.com，免费），新建 **Blueprint** → 选择该 GitHub 仓库 → Render 读取 `render.yaml` 自动配置。
4. 在 Render 的 Environment 里填两项（仓库不存明文）：
   - `ZHIPU_API_KEY` = 你的智谱免费 key
   - `ADMIN_PASSWORD` = 你想设的后台密码
5. 点 Deploy，约 1–2 分钟后得到 `https://xxxx.onrender.com` 公网地址，发给学生即可。

**部署后还能改网页吗？——能。** 你在本机改 `templates/student.html`（页面）、`prompts.py`（AI 话术）、`app.py`（功能）后，提交并推送到 GitHub，Render **自动重新部署**，约 1–2 分钟生效，无需重填任何配置。

**学生用手机流量能用吗？——能。** Render 提供 HTTPS 公网地址，学生手机只要有流量/网络，浏览器打开链接即可使用；页面已做手机适配（按钮够大、竖屏单列）。

**⚠️ 数据持久化提示（正式收数据前必读）**：Render 免费层的磁盘是**临时**的——每次重新部署或实例休眠唤醒，本机 `conversations.db` 会重置，**学生对话可能丢失**。因此：
- 试测 / 演示阶段可直接用，方便；
- 正式开始收过程性数据前，把数据库换成**持久化方案**（推荐免费 Turso 云 SQLite，或 PythonAnywhere 持久磁盘），改动很小、不影响现有功能与导出。需要时在 WorkBuddy 里让我改即可。
